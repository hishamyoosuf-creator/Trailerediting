
# Trailer Hook Strategy

The opening of a trailer must create
curiosity and make the audience interested.

## Hook Categories

### 1. Dialogue Hook
Start with a powerful movie dialogue.

### 2. Mystery Hook
Show an unexplained visual or event.

### 3. Emotional Hook
Use a powerful emotional scene.

### 4. Suspense Hook
Build tension using sound and visuals.

### 5. Visual Hook
Start with an unusual cinematic image.

## Instructions

Generate at least 5 possible hook ideas
when sufficient footage is available.

For every hook provide:

- Source footage filename
- Source timecode
- Dialogue if applicable
- Suggested duration
- Sound design suggestion
- Reason for selecting the hook

Never fabricate source timecodes.
